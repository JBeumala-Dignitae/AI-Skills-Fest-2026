# Dignitae | AI Skills Fest 2026

## Workshop: Crea un Agente de Registro Horario Inteligente con Microsoft Foundry

¡Bienvenido al repositorio del workshop realizado en el **AI Skills Fest 2026** por el equipo de **Dignitae**! 

En este taller práctico hemos visto como diseñar, desarrollar y desplegar un agente inteligente integrado con Microsoft Foundry, capaz de automatizar y optimizar la gestión del registro horario laboral mediante el uso de inteligencia artificial.

---

## 📂 Estructura del Repositorio

El proyecto está organizado en los siguientes directorios:

* **`API/`**: Contiene el código fuente de la aplicación de registro horario base utilizada para gestionar las jornadas, entradas y salidas.
* **`WebApp/`**: Aloja la aplicación de interfaz de usuario (Front-end), donde se integra y realiza la llamada al agente inteligente.
* **`Documentos/`**: Incluye recursos didácticos, guías de configuración y documentación adicional sobre el evento y las tecnologías utilizadas.
